# Notes for agents

- **Commits** follow the rules in [CONTRIBUTING.md](CONTRIBUTING.md#commit-messages): Conventional Commits with a type
  and a scope, `<type>(<scope>): <summary in imperative mood>`. Read that section before you commit. A change of how the
  app looks is a `feat` or a `fix`; `style` is only for the formatting of code.
- Keep one concern per commit and split a change that mixes several.
- Code style, checks and tests are in [CONTRIBUTING.md](CONTRIBUTING.md#code-style). Run them before you commit.
